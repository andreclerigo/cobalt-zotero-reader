Zotero Reader

Your Zotero reading lists on a Kobo, with a serverless core and an optional rich-PDF conversion service.

Status: personal managed built-in under active testing. It is not yet a public Cobalt Store app.

Direct mode

The Kobo reads collections, metadata, abstracts, and Zotero indexed text directly from Zotero API v3. No personal server is required.

Set up direct mode →

Bridge mode

An optional FastAPI and Docling service converts stored Zotero PDFs into structured HTML with tables, formulas, OCR, and figures.

Deploy the bridge →

What it does

  • Lists up to 100 Zotero collections and lets you switch between them from the feed.
  • Keeps a separate cached snapshot for each selected collection and displays the newest 500 items.
  • Searches cached titles, authors, and tags on the reader.
  • Keeps up to 96 explicitly selected text documents offline, with position and annotations.
  • Never writes to Zotero and never scrapes Google Scholar or follows publisher links.

Privacy boundary

The direct Zotero key is stored by the Cobalt runtime and is available only to the exact read routes authorized for the runtime-verified zotero-reader app ID. The app never sees the secret value. The optional bridge uses a different token bound to one compiled HTTPS origin and its /v1/ API. Credentialed redirects are refused.

Development documentation. No account credentials or private library data are included in this site.
