Set up direct mode

Start here. A Zotero account and a compatible Cobalt development package are enough; the conversion bridge is optional.

1. Prepare Zotero

  1. Create one or more Zotero collections and add papers to them. A stored PDF is needed for full text.
  2. Create a dedicated Zotero API key with read-only library and file access.
  3. Record the numeric user ID shown on the key page. It is not your username.
Do not put the API key in Git, a URL, a build flag, or a screenshot.

2. Install the secret

From the Cobalt repository, run the interactive secret command:

cargo run -p kobo-cli -- secret set zotero --device <address>

The command prompts for the value without placing it in shell history. Install or deploy the local package using the normal Cobalt development workflow for your supported device.

3. Launch Zotero Reader

  1. Enter the numeric user ID.
  2. If Zotero returns one collection, it opens automatically. If it returns several, choose one.
  3. Use Collections in the feed header whenever you want to switch. Use Offline to open kept papers.

The app remembers the selected collection and stores a separate bounded snapshot for each collection you open. Refresh and search apply to the collection named at the top of the screen.

4. Read a paper

Open an item to see its metadata and abstract. In direct mode, Open Zotero indexed text asks Zotero for the stored attachment's plain-text index. A linked file or publisher URL is not downloaded. Position and annotations are saved as private Cobalt shelf data.

Limits in direct mode

  • The collections request is bounded to the first 100 collections sorted by title.
  • Each collection snapshot contains at most the newest 500 top-level items.
  • Zotero indexed text does not preserve figures, tables, formulas, OCR layout, or PDF pagination.
  • Figures require the optional bridge and remain online-only in v1.
